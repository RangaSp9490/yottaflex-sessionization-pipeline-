# AI assistance disclosure — complete honestly before submission

The assessment guidelines require prompt history and disclosure of AI assistance.

- Tool used: ChatGPT (OpenAI).
- Assistance: interpreting the brief, proposing a structure, drafting initial code/tests/documentation.
- Add the actual prompts from your conversation and any additional tools used.
- Before submission, personally read the code, run tests, inspect outputs, check reconciliation, run a larger-data test, and record what you changed.
- Do not claim to have personally authored or verified code unless accurate.

Be prepared to explain: session boundary semantics, out-of-order sorting, duplicate policy, rejection reasons, reconciliation checks, and the in-memory performance limitation.
